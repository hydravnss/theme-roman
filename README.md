# Thème Roman

Extension [SillyTavern](https://github.com/SillyTavern/SillyTavern) : une mise en page de chat typographique, sans bulles.

- Police Apple (San Francisco) dans le chat, texte de dialogue en blanc gras
- Les actions en italique (`*…*`) ont une couleur réglable (doré par défaut)
- Messages du personnage : photo carrée arrondie + nom + menu `…`
- Tes messages : texte seul, sans avatar ni nom
- Ne déplace pas la barre de saisie et ne touche pas à la hauteur de l’écran

## Réglages

Dans **Extensions → Thème Roman** : activer ou désactiver, et choisir la couleur de l’italique.

## Installation

Déjà installée sur l’instance qui l’embarque. Sinon, dossier `theme-roman` dans `data/<user>/extensions/`.
